## القسم الأول: فترة الضمان

### المدة: 30 يوماً من التسليم النهائي

### ما يشمله الضمان:

| البند | مشمول | غير مشمول |
|-------|-------|-----------|
| أخطاء برمجية في الكود | ✓ | |
| خلل في الوظائف المُتفق عليها | ✓ | |
| مشاكل في قاعدة البيانات | ✓ | |
| تعديلات على الميزات | | ✗ |
| إضافة ميزات جديدة | | ✗ |
| تغيير التصميم | | ✗ |
| مشاكل الخادم | | ✗ |
| أخطاء المستخدم | | ✗ |

### تعريف "الخطأ البرمجي":
- ميزة لا تعمل كما هو موصوف في نطاق العمل
- النظام يتوقف عن العمل بدون سبب خارجي
- بيانات تُفقد أو تُتلف بسبب الكود

### ليس خطأً برمجياً:
- الميزة تعمل لكن العميل يريدها بشكل مختلف
- بطء بسبب ضعف الخادم
- مشكلة بسبب تعديل العميل على الكود
- مشكلة بسبب خدمة خارجية (SMS، الاستضافة)

### طريقة الإبلاغ عن مشكلة:
1. وصف المشكلة بوضوح
2. خطوات إعادة إنتاج المشكلة
3. لقطة شاشة إن أمكن
4. الإرسال عبر البريد الإلكتروني

### وقت الاستجابة خلال الضمان:
| نوع المشكلة | وقت الاستجابة | وقت الحل |
|-------------|---------------|----------|
| النظام متوقف كلياً | خلال 4 ساعات | خلال 24 ساعة |
| ميزة أساسية معطلة | خلال 24 ساعة | خلال 72 ساعة |
| مشكلة ثانوية | خلال 48 ساعة | خلال أسبوع |

## القسم الثاني: بعد انتهاء الضمان

### الخيار 1: بدون عقد صيانة

**ما يحدث:**
- لا دعم فني
- لا تحديثات
- العميل مسؤول عن كل شيء

**مناسب لـ:**
- من لديه فريق تقني داخلي
- من لا يحتاج تحديثات

**التكلفة:** مجاناً (لا التزامات)

---

### الخيار 2: دعم عند الطلب (Pay-per-Incident)

**ما يشمله:**
- حل المشاكل عند الطلب
- بدون التزام شهري

**التسعير:**
| نوع العمل | السعر |
|-----------|-------|
| استشارة (بالساعة) | 50$/ساعة |
| إصلاح خطأ برمجي | 100-300$ حسب التعقيد |
| تعديل بسيط | 200-500$ |
| ميزة جديدة صغيرة | يُقدَّر بشكل منفصل |

**طريقة الطلب:**
1. وصف المشكلة/الطلب
2. نُرسل تقدير التكلفة
3. موافقة العميل
4. تنفيذ العمل
5. الدفع عند الإتمام

**ملاحظة:** لا ضمان على وقت الاستجابة (حسب التوفر)

## القسم الرابع: مسؤوليات العميل

بغض النظر عن نوع الدعم، العميل مسؤول عن:

### 1. البنية التحتية
- دفع رسوم الاستضافة
- توفير خادم بالمواصفات المطلوبة
- اتصال إنترنت مستقر

### 2. النسخ الاحتياطي
- تفعيل النسخ الاحتياطي الآلي
- اختبار الاستعادة دورياً
- حفظ نسخ خارج الخادم

### 3. الأمان
- كلمات مرور قوية
- عدم مشاركة بيانات الدخول
- إبلاغنا عن أي نشاط مشبوه

### 4. التحديثات
- إبلاغنا قبل تعديل الكود
- عدم تثبيت برامج غير موثوقة على الخادم

## القسم الخامس: إنهاء الدعم

### إنهاء من جانب العميل:
- إشعار قبل 30 يوماً
- دفع المستحقات المتبقية
- لا غرامات

### إنهاء من جانب المُطوِّر:
- إشعار قبل 60 يوماً
- استرداد نسبي للمدفوعات المسبقة
- تسليم أي أعمال قيد التنفيذ

### في حالة الإنهاء:
- العميل يحتفظ بالكود والبيانات
- نُقدم وثائق التسليم لطرف ثالث إن طُلب
- لا التزامات مستقبلية
