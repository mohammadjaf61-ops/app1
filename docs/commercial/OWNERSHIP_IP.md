## القسم الثاني: المكتبات والأدوات الخارجية

### مكونات مفتوحة المصدر (Open Source):

النظام يستخدم مكتبات مفتوحة المصدر مرخصة بشكل يسمح بالاستخدام التجاري:

| المكتبة | الترخيص | الاستخدام |
|---------|---------|----------|
| NestJS | MIT | الخدمة الخلفية |
| React | MIT | واجهات الويب |
| React Native | MIT | التطبيقات |
| PostgreSQL | PostgreSQL License | قاعدة البيانات |
| Redis | BSD | التخزين المؤقت |
| Tailwind CSS | MIT | التصميم |

**ما يعنيه هذا:**
- هذه المكتبات مجانية للاستخدام التجاري
- لا رسوم ترخيص
- العميل ملزم باحترام شروط كل مكتبة (عادةً: الإبقاء على إشعار حقوق النشر)

### خدمات خارجية:

| الخدمة | المسؤولية | الملاحظة |

| استضافة الخادم | العميل | رسوم شهرية لمزود الخدمة |

| بيانات المخزون | **العميل** |
| سجلات النظام | **العميل** |
| كل البيانات المُدخَلة | **العميل** |

### حقوق العميل على البيانات:
- الوصول الكامل في أي وقت
- تصدير البيانات بصيغ قياسية
- حذف البيانات
- نقل البيانات لنظام آخر

### التزامات المُطوِّر:
- عدم الوصول للبيانات إلا للدعم الفني (بإذن)
- عدم نسخ أو مشاركة بيانات العميل
- عدم استخدام البيانات لأي غرض آخر
- حذف أي نسخ عند انتهاء العلاقة

### بيانات العملاء (المستخدمين النهائيين):
- العميل هو "المتحكم بالبيانات" قانونياً
- العميل مسؤول عن الامتثال لقوانين الخصوصية
- النظام يوفر أدوات للامتثال (سياسة خصوصية، موافقة المستخدم)

## القسم الخامس: السرية

### معلومات سرية من جانب العميل:
- بيانات العملاء والمبيعات
- استراتيجيات التسعير
- خطط العمل
- أي معلومات يحددها العميل كسرية

### معلومات سرية من جانب المُطوِّر:
- طرق العمل الداخلية
- أسعار التكلفة
- معلومات عملاء آخرين

### الالتزامات:
- عدم إفشاء المعلومات السرية لأي طرف ثالث
- استخدام المعلومات فقط لأغراض المشروع
- إعادة أو حذف المعلومات السرية عند الطلب

### مدة السرية: 3 سنوات بعد انتهاء العقد

### استثناءات:
- معلومات أصبحت عامة بدون خطأ من الطرف المتلقي
- معلومات مطلوبة قانونياً (بإخطار الطرف الآخر)

## القسم السادس: نقل الملكية

### متى تنتقل الملكية:
- الكود: عند الدفع الكامل (100%)
- البيانات: ملك العميل منذ إدخالها
- التوثيق: عند التسليم النهائي

### في حالة عدم إتمام الدفع:
- الكود يبقى ملك المُطوِّر
- البيانات تبقى ملك العميل (يتم تسليمها)
- حق استخدام النظام يتوقف

### في حالة النزاع:
- الطرفان يحاولان الحل الودي أولاً
- التحكيم إن فشل الحل الودي
- القانون المعمول به: [يُحدد في العقد]

---

## القسم السابع: بعد انتهاء العلاقة

### حقوق العميل:
- الاحتفاظ بالكود والبيانات
- تعديل النظام بأي طريقة
- التعاقد مع مطور آخر
- بيع أو ترخيص النظام

### التزامات المُطوِّر:
- تسليم أي مواد متبقية
- حذف نسخ الكود والبيانات
- عدم استخدام معلومات العميل السرية

### التزامات العميل:
- دفع أي مستحقات متبقية
- عدم استخدام اسم المُطوِّر بشكل مضلل
